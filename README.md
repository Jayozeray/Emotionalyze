# Emotionalyze  
Тема - Распознавание эмоций зрителя для получения субъективной оценки эмоциональности видеофрагмента.

## Состав

- `main.py` – точка входа;
- `gui.py` – графический интерфейс (PySide6);
- `backend.py` – покадровый анализ видео (OpenCV, DeepFace);
- `emotion_map_io.py` – чтение и запись эмоциональных карт (JSON);
- `comparison.py` – методы сравнения эмоциональных карт;
- `experiments.py` – пакетное экспериментальное исследование методов сравнения.

## Формат эмоциональной карты

```
[
  {"fps": 30},
  {"percentages": {"angry": ..., ...}},
  {"dominant": "neutral", "inferior": "sad", "probs": {"angry": 0.01, ..., "neutral": 0.71}},
  ...
]
```

Поле `probs` (полный вектор вероятностей) появилось в версии 0.5 и необязательно:
карты, сохранённые предыдущими версиями, читаются без изменений, для них вектор
строится по доминантной и уступающей эмоции (1 и α).

## Методы сравнения

По результатам экспериментального исследования по умолчанию используется
комбинированная оценка из динамического выравнивания (вес 0,5) и частотного
распределения эмоций (вес 0,5) с исключением безэмоциональных фрагментов и
максимальным сдвигом 2 с. Вердикт выдаётся по правилу: среднее сходство
тестируемой карты с эталонами не ниже среднего сходства эталонов между собой.

В интерфейсе в блоке «Параметры сравнения» выбирается:

- метод: базовый алгоритм, векторный метод, динамическое выравнивание (DTW),
  частотное распределение, комбинированная оценка или все методы сразу;
- максимальный сдвиг, с (пересчитывается в кадры по частоте кадров карты);
- окно сглаживания карты, кадров (0 – без сглаживания);
- вес уступающей эмоции α (по умолчанию 0,5);
- исключение безэмоциональных фрагментов (пар кадров, где в обеих картах
  доминирует нейтральная эмоция);
- веса комбинированной оценки (по умолчанию 0 / 0 / 0,5 / 0,5; экспертные веса
  из отчёта за 2 семестр – 0,25 / 0,35 / 0,30 / 0,10).

Кнопка «Межэталонное сравнение» считает среднее сходство эталонных карт между собой
(критерий оценки тестируемой карты). Все результаты сравнения можно сохранить в CSV.

## Экспериментальное исследование

```
python experiments.py --config experiment_config.json --out results
```

Пример конфигурации – `experiment_config.example.json`. Результаты сохраняются в виде
CSV-таблиц (разделитель «;»).
